# 📚 Actividad 1 - Frontend "Relatos de Papel"

> Requisitos académicos para la entrega del front-end.

---

## 🎯 Objetivo

Desarrollar el **front-end** de una aplicación web de librería usando **React**, aplicando:

- HTML5, CSS3 (metodología BEM), JavaScript ES6
- React: componentes funcionales, hooks, React Router v6

---

## 📋 Requisitos Técnicos

| Requisito                       | Mínimo      |
| ------------------------------- | ----------- |
| Componentes funcionales React   | 10          |
| Hooks (`useState`, `useEffect`) | Obligatorio |
| Custom Hook                     | 1           |
| Rutas (React Router)            | 4           |
| CSS con metodología BEM         | Obligatorio |

---

## 📄 Vistas Requeridas

| Vista                | Funcionalidad                                           |
| -------------------- | ------------------------------------------------------- |
| **Landing**          | Redirección automática a Home (5s)                      |
| **Home**             | Catálogo + búsqueda por título                          |
| **Detalle de Libro** | Info completa + añadir al carrito                       |
| **Carrito**          | Visible siempre, eliminar items, ir a checkout          |
| **Checkout**         | Resumen, simular pago, vaciar carrito, redirigir a Home |

**Simplificaciones**: No requiere login. Usar datos mock (sin backend).

---

## 📦 Entregables

1. **Videomemoria (MP4)** - Máx. 10 min

   - Componentes React desarrollados
   - Hooks utilizados (incluyendo custom hooks)
   - Demo de vistas locales + estilos CSS destacables
   - Demo del despliegue en Vercel

2. **URL de Vercel** (archivo TXT)

3. **Código fuente** (sin `node_modules`)
